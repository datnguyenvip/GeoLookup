# GeoLookup
GeoLookup là phần mềm tra cứu quy đổi bản đồ địa chính sau sắp xếp đơn vị hành chính.
Phần mềm tra cứu quy đổi bản đồ địa chính sau sắp xếp đơn vị hành chính.
## Phiên bản hiện có

### GeoLookup LA

Tra cứu quy đổi:

Long An → Tây Ninh

Phiên bản: 1.0
## Trạng thái

🟢 Đang phát triển

Phiên bản đầu tiên:

GeoLookup LA v1.0

## Tải phần mềm

Vào mục **Releases** để tải file cài đặt mới nhất.

## Cài đặt

1. Tải file `GeoLookupLA_Setup_v1.0.exe`
2. Mở file cài đặt
3. Chọn Next → Install → Finish
4. Mở GeoLookup LA từ Desktop
